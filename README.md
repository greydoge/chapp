# Chaff

## Install

The app lives in `app/`.

```bash
cd app
npm install
```

## Run

Start the local dev server:

```bash
cd app
npm run dev
```

Vite will print a local URL, usually on `http://localhost:5173`.

## Build

Create a production build:

```bash
cd app
npm run build
```

The built files are written to `app/dist/`.

## Preview

Serve the production build locally:

```bash
cd app
npm run preview
```

## Test

Run the test suite:

```bash
cd app
npm test
```

## Notes

- The client is browser-based and runs on Linux, macOS, and Windows.
- For production, use the built `dist/` output rather than the Vite dev server.
